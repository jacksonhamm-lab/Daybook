# Vision

What Daybook should look and feel like. Check new work against this.

## What it is

A private daybook for Jackson: tasks, work hours and pay, training, job applications
and notes, with a game layer (XP, levels, Dex and his attributes) on top.
It should feel like a game menu you want to open, not a spreadsheet.

## Principles

1. **Animated on purpose.** Things move to explain what happened: a button grows into
   the page it opens, a finished task slides away, numbers count up. Motion is part of
   the design, not decoration added after.
2. **Scenes, not grids.** Each tab should read as one continuous scene (like the health
   insights reference), not a stack of tiles. Today's current tile layout is a step
   toward this, not the end state.
3. **A few buttons, then depth.** The top level is a small menu of big choices. Tapping
   one opens the bigger view seamlessly, and closing returns you to where you were.
4. **Dense but calm.** Lots of information, but only one detail open at a time.
   Collapse by default, expand on tap.
5. **One way to do each thing.** No duplicate buttons for the same action.
6. **Useful first.** Every animated or game element has to point at real data.

## Look

- Dark navy base with soft blue-to-rose light beams.
- Open detail cards flip to light (off-white) with dark text.
- Type: Inter for text, Unbounded for numbers and titles.
- Colour per area: Tasks blue, Hours teal, Training orange, Cardio pink, Jobs green,
  Notes purple, Fuel yellow.

## Rejected (don't go back)

- Cyberpunk / HUD / "Jarvis" dashboards.
- The plain first version that looked like the workout app.
- The 16-week consistency heatmap ("makes absolutely no sense"). Use weekly bars.
- The particle-figure player model. It became the 3D character.
- A robot character. Dex is a skier.
- Bolting a new element onto the old layout and calling it a redesign.

## Tone

- Short, plain labels. No filler.
- Dex speaks in short, useful lines about the actual day.
